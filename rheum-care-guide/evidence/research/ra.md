# Rheumatoid arthritis (類風濕性關節炎) — lifestyle & self-care evidence file

Compiled 2026-10-06 following `/home/claude/research/PROTOCOL.md`. Evidence file only — no patient-facing text.

**Reading notes / legend**
- **Access codes.** *FT-PMC* = full text retrieved with the PubMed `get_full_text_article` tool (raw text; formatted words can be dropped — see pitfall box). *FT-WF* = full text read with WebFetch, a summarising fetcher that returns quotes of ≤125 characters; long statements came back as consecutive fragments and are re-joined here with single spaces. "2 passes" / "2 copies" = identical wording returned by two independent fetches, or from two different copies of the document. **"WF-1"** = wording seen in one pass only; **spot-check against the PDF before publication**. *AM* = ACR author manuscript (CDC Stacks record cdc/151745: PDF `DS1` and NIHMS XML `DS2`), read via WebFetch. *Abs* = PubMed abstract only.
- In quotes, empty brackets "()" or "[,]" and words glued to them (e.g. "RCTsand") are citation markers stripped by the extractor, not missing words, unless flagged otherwise. "\*" is a Markdown escape for an asterisk printed in the source. "[sic]" marks an error in the source.
- ACR statement numbers are ours (order of appearance within each section); the ACR text does not number them.
- **Confidence:** High = explicit in Tier-1 full text read this session; Medium = Tier-2, or Tier-1 abstract-only, or a Tier-3 trial's own primary result (abstract); Low = secondary source or indirect. Where a clinician-directed statement is turned into a patient message, both levels are given (e.g. "High (statement) / Low (as patient message)").

**Extraction-pitfall box (ACR 2022, PMC10947582).** In the PMC text, three statements end "…is conditionally recommended." with no comparator: formally defined diets other than Mediterranean, electrotherapy, and chiropractic. In every case the true direction is **AGAINST**. I confirmed this five ways: (1) the AM PDF reads "conditionally recommended against"; (2) the NIHMS XML wraps the word as `<italic toggle="yes">against</italic>`, which shows the extractor drops italic text; (3) the Guideline Central summary reads "We conditionally recommend against…"; (4) the PMC text itself contains "recommendation for “not” using…" / "the Voting Panel recommended against electrotherapy" / "only a Mediterranean-style diet had sufficient evidence to be recommended"; (5) the ACR press release says "Mediterranean-style diet but not other formally defined diets". The PMC text also dropped "no" from one orthoses evidence sentence (the AM reads "(no studies met eligibility criteria for this PICO)"). No other ACR statement lacks a comparator; all others read "…recommended over no …", so their direction is unambiguous.
