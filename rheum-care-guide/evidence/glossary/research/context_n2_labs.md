## ana — 抗核抗體（ANA）
aliases on site: 抗核抗體, ANA   (category: test; link scope: page)
- [LINK] labs / labs-intro (intro) 「抗核抗體」: 健檢報告出現抗核抗體、類風濕因子、抗CCP抗體陽性或尿酸偏高時，這頁說明它們的意思；是否生病，要由醫師合併症狀與檢查判斷。
- [repeat] labs / labs-ana (title) 「抗核抗體」: 抗核抗體陽性
- [repeat] labs / LB-1.1 (text) 「抗核抗體」: 健康的人也可能驗出抗核抗體（ANA）陽性：1:40以上約20%、最多可達35%，1:160以上約5%。  〔CRA 2015・指引說明；ICAP 2019・專家共識〕
- [repeat] labs / LB-1.1 (text) 「ANA」: 健康的人也可能驗出抗核抗體（ANA）陽性：1:40以上約20%、最多可達35%，1:160以上約5%。  〔CRA 2015・指引說明；ICAP 2019・專家共識〕
- [repeat] labs / LB-1.2 (text) 「抗核抗體」: 抗核抗體數值越高（如1:160高於1:40），和自體免疫風濕病關聯越強。  〔ICAP 2019・專家共識〕
- [repeat] labs / LB-1.3 (text) 「抗核抗體」: 單看報告上的抗核抗體型態，通常不能確定和哪一種疾病有關，要由醫師配合症狀判斷。  〔ICAP 2019・專家共識〕
- [repeat] labs / LB-1.4 (text) 「抗核抗體」: 不同醫院或檢驗所的抗核抗體檢驗方法、陽性切點可能不同，結果不一定一致。  〔EASI/IUIS 2014・專家共識；ICAP 2019・專家共識〕
- [repeat] labs / LB-1.T (text) 「抗核抗體」: 沒有相關疾病表現、卻驗出抗核抗體陽性的情況越來越多，可能和真正有病的陽性一樣常見。  〔ICAP 2019・專家共識〕
- [repeat] labs / labs-sle (title) 「抗核抗體」: 抗核抗體與紅斑性狼瘡
- [repeat] labs / labs-sle (summary) 「抗核抗體」: 抗核抗體陽性只是入門條件，不等於紅斑性狼瘡。
- [repeat] labs / LB-2.1 (text) 「抗核抗體」: 國際紅斑性狼瘡分類標準中，抗核抗體陽性（1:80以上）只是入門條件。  〔EULAR/ACR 2019・指引說明〕
- [repeat] labs / LB-2.T (text) 「抗核抗體」: 抗核抗體被當成入門條件，考量之一是：紅斑性狼瘡患者幾乎都會陽性，但沒有這個病的人也可能陽性。  〔EULAR/ACR 2019・指引說明〕
- [repeat] labs / labs-ana-screening (title) 「抗核抗體」: 抗核抗體不是篩檢工具
- [repeat] labs / labs-ana-screening (summary) 「抗核抗體」: 沒有特定症狀時，不建議用抗核抗體篩檢。
- [repeat] labs / LB-4.1 (text) 「抗核抗體」: 沒有紅斑性狼瘡或其他結締組織疾病的特定症狀或徵象時，不建議把抗核抗體當成篩檢。  〔CRA 2015・不建議〕
- [repeat] labs / LB-4.2 (text) 「抗核抗體」: 醫師評估後不懷疑免疫疾病時，即使抗核抗體陽性，也不建議再加驗相關的特定抗體。  〔ACR 2013・強烈不建議（1C）〕
- [repeat] labs / LB-M1 (belief) 「抗核抗體」: 抗核抗體陽性，就是得了紅斑性狼瘡。  〔CRA 2015・指引說明；ICAP 2019・專家共識；EULAR/ACR 2019・指引說明〕
- [repeat] labs / LB-M1 (fact) 「抗核抗體」: 不一定。以1:40檢驗，健康的人約20%、最多35%會陽性；抗核抗體只是紅斑性狼瘡分類的入門條件，診斷要由醫師評估。  〔CRA 2015・指引說明；ICAP 2019・專家共識；EULAR/ACR 2019・指引說明〕

## rf — 類風濕因子（RF）
aliases on site: 類風濕因子, RF   (category: test; link scope: page)
- [LINK] labs / labs-intro (intro) 「類風濕因子」: 健檢報告出現抗核抗體、類風濕因子、抗CCP抗體陽性或尿酸偏高時，這頁說明它們的意思；是否生病，要由醫師合併症狀與檢查判斷。
- [repeat] labs / labs-rf-ccp (title) 「類風濕因子」: 類風濕因子與抗CCP
- [repeat] labs / LB-3.1 (text) 「類風濕因子」: 類風濕因子（RF）陽性，不一定是類風濕性關節炎；沒有這個病的人也可能驗出陽性。  〔Nishimura 2007・研究顯示〕
- [repeat] labs / LB-3.1 (text) 「RF」: 類風濕因子（RF）陽性，不一定是類風濕性關節炎；沒有這個病的人也可能驗出陽性。  〔Nishimura 2007・研究顯示〕
- [repeat] labs / LB-3.2 (text) 「類風濕因子」: 沒有類風濕性關節炎的人，抗CCP抗體陽性的機會比類風濕因子低。  〔Nishimura 2007・研究顯示〕
- [repeat] labs / LB-3.4 (text) 「類風濕因子」: 類風濕因子或抗CCP抗體陰性，也不能排除類風濕性關節炎：研究中，每種抗體都有3成以上的患者是陰性。  〔Nishimura 2007・研究顯示〕
- [repeat] labs / LB-M2 (belief) 「類風濕因子」: 類風濕因子陽性，就是得了類風濕性關節炎。  〔ACR/EULAR 2010・指引說明；Nishimura 2007・研究顯示〕
- [repeat] labs / LB-S2 (text) 「類風濕因子」: 關節持續腫脹，應請專科醫師評估；如果手腳小關節腫、不只一個關節腫，或症狀已3個月以上還沒看醫師，即使類風濕因子或抗CCP抗體陰性，也應盡快評估。  〔NICE NG100・建議〕

## false-results — 假陽性與假陰性
aliases on site: 假陽性, 偽陰性   (category: test; link scope: card)
- [LINK] labs / LB-4.3 (text) 「假陽性」: 檢查結果不會改變處理方式，或生病機會低到假陽性比真陽性更可能時，就不建議檢查。  〔ACR 2013・指引說明〕
- [repeat] labs / LB-4.4 (text) 「假陽性」: 沒有方向、範圍很廣的檢查，可能增加假陽性，帶來不必要的追加檢查和擔心。  〔ACR 2013・指引說明〕
- [LINK] infection / IF-2.T (text) 「偽陰性」: 免疫力較低時，潛伏結核檢驗可能出現偽陰性；有風險因子或日後出現風險因子時，醫師可能考慮定期再篩檢。  〔疾管署・指引說明；EULAR 2022・指引說明〕

## classification-criteria — 分類標準
aliases on site: 分類標準   (category: evidence; link scope: page)
- [LINK] labs / LB-2.1 (text) 「分類標準」: 國際紅斑性狼瘡分類標準中，抗核抗體陽性（1:80以上）只是入門條件。  〔EULAR/ACR 2019・指引說明〕
- [repeat] labs / LB-2.3 (text) 「分類標準」: 在紅斑性狼瘡分類標準中，每一項表現都要在沒有其他更可能的原因時，才能算分。  〔EULAR/ACR 2019・基本原則〕
- [repeat] labs / LB-2.4 (text) 「分類標準」: 分類標準不是設計來診斷或決定治療的；是否為紅斑性狼瘡，要由受過適當訓練的醫師評估個人狀況來判斷。  〔EULAR/ACR 2019・指引說明〕
- [repeat] labs / labs-rf-ccp (summary) 「分類標準」: 陽性不等於類風濕性關節炎；分類標準要求關節腫脹。
- [repeat] labs / LB-3.3 (text) 「分類標準」: 類風濕性關節炎的分類標準，要先有至少1個關節腫脹（經專業評估），且沒有其他疾病更能解釋，才能套用。  〔ACR/EULAR 2010・指引說明〕
- [repeat] labs / LB-3.T (text) 「分類標準」: 類風濕性關節炎的分類標準主要是為研究而訂，不是診斷標準。  〔ACR/EULAR 2010・指引說明〕
- [repeat] labs / LB-M2 (fact) 「分類標準」: 不一定。沒有這個病的人也可能陽性；國際分類標準規定，至少要有1個關節腫脹才能套用，單靠抽血不行。  〔ACR/EULAR 2010・指引說明；Nishimura 2007・研究顯示〕
