## ltbi — 潛伏結核
aliases on site: 潛伏結核   (category: condition; link scope: page)
- [LINK] infection / infection-tb (title) 「潛伏結核」: 結核病與潛伏結核
- [repeat] infection / infection-tb (summary) 「潛伏結核」: 用生物製劑前先驗潛伏結核；陽性時把治療完整做完。
- [repeat] infection / IF-2.2 (text) 「潛伏結核」: 用生物製劑或口服標靶藥物前，要先篩檢潛伏結核；風險較高的人，用其他抗風濕藥物或類固醇前也可能需要。  〔EULAR 2022・建議強度 B/D；BSR 2019・強烈建議（1B）〕
- [repeat] infection / IF-2.4 (text) 「潛伏結核」: 潛伏結核檢驗陽性時，通常要先開始潛伏結核治療，再用生物製劑；治療完整做完，才能提供約 9 成的保護。  〔BSR 2019・建議（2C）；疾管署・指引說明〕
- [repeat] infection / IF-2.4 (text) 「潛伏結核」: 潛伏結核檢驗陽性時，通常要先開始潛伏結核治療，再用生物製劑；治療完整做完，才能提供約 9 成的保護。  〔BSR 2019・建議（2C）；疾管署・指引說明〕
- [repeat] infection / IF-2.5 (text) 「潛伏結核」: 接受潛伏結核治療時，建議參加「都治」計畫：由關懷員送藥、留意副作用，幫助治療成功、避免抗藥性。  〔疾管署・建議〕
- [repeat] infection / IF-2.T (text) 「潛伏結核」: 免疫力較低時，潛伏結核檢驗可能出現偽陰性；有風險因子或日後出現風險因子時，醫師可能考慮定期再篩檢。  〔疾管署・指引說明；EULAR 2022・指引說明〕
- [repeat] infection / IF-M2 (belief) 「潛伏結核」: 驗出潛伏結核，就是得了肺結核，會傳染給家人。  〔疾管署・指引說明〕
- [repeat] infection / IF-M2 (fact) 「潛伏結核」: 潛伏結核是感染了結核菌、但還沒發病，沒有症狀，也還不會傳染。完整接受治療，可提供約 9 成的保護，避免日後發病。  〔疾管署・指引說明〕
- [repeat] infection / IF-M3 (fact) 「潛伏結核」: 不只生物製劑。有些證據顯示，使用類固醇或傳統抗風濕藥物，潛伏結核再活化的風險也會增加；疾管署也指出，免疫風濕病人因疾病本身和類固醇、免疫抑制劑治療，結核病風險比一般人高出許多。  〔EULAR 2022・指引說明；疾管署・指引說明〕

## igra — 潛伏結核檢驗（IGRA 與皮膚測試）

- [repeat] infection / IF-2.3 (text) 「皮膚測試」: 結核病篩檢通常包括胸部 X 光和抽血檢驗（IGRA）；有條件時，優先用抽血檢驗，而不是皮膚測試。  〔EULAR 2022・建議強度 B/D〕

- [repeat] infection / IF-3.1 (text) 「表面抗體」: 開始免疫抑制治療前，都應檢查 B 型肝炎表面抗原、表面抗體和核心抗體；類固醇則依劑量和使用時間決定。  〔EULAR 2022・建議強度 C；APASL 2021・建議〕
- [repeat] infection / IF-3.1 (text) 「核心抗體」: 開始免疫抑制治療前，都應檢查 B 型肝炎表面抗原、表面抗體和核心抗體；類固醇則依劑量和使用時間決定。  〔EULAR 2022・建議強度 C；APASL 2021・建議〕

- [repeat] infection / IF-3.4 (text) 「表面抗原」: 曾感染過 B 型肝炎（核心抗體陽性、表面抗原陰性）的人，再活化風險較低，通常定期抽血追蹤；部分用藥則可能需要抗病毒藥。  〔EULAR 2022・指引說明〕

## hbv-reactivation — B 型肝炎再活化
aliases on site: B 型肝炎再活化   (category: condition; link scope: card)
- [LINK] infection / IF-3.2 (text) 「B 型肝炎再活化」: 免疫抑制治療可能讓 B 型肝炎再活化（再度活躍），已痊癒者也可能。類固醇看劑量：帶原者持續用較高劑量風險中到高，低劑量或已痊癒者風險較低。  〔BSR 2025・指引說明；APASL 2021・指引說明〕

## tsdmard — 口服標靶藥物（JAK 抑制劑）

- [repeat] infection / IF-5.2 (text) 「口服標靶藥物」: 使用 JAK 抑制劑（一種口服標靶藥物）時，帶狀疱疹比使用生物製劑時更常見。  〔國際共識 2024・建議強度 B〕

## adrenal — 腎上腺功能不足與腎上腺危象
aliases on site: 腎上腺功能不足, 腎上腺危象   (category: condition; link scope: card)
- [LINK] infection / IF-4.2 (text) 「腎上腺危象」: 不要漏吃或自行突然停用類固醇；口服劑量高於身體自然分泌量時，藥量突然不足可能引起需緊急處理的腎上腺危象。  〔ESE/ES 2024・指引說明〕
- [repeat] infection / IF-4.3 (text) 「腎上腺功能不足」: 長期用或剛停用類固醇的人，發燒或感染需用抗生素時，可能需要暫時補充類固醇，以免腎上腺功能不足（不是治療感染）；請事先問醫師，感染也要就醫。  〔ESE/ES 2024・良好實務建議〕

## pjp — 肺囊蟲肺炎
aliases on site: 肺囊蟲肺炎   (category: condition; link scope: card)
- [LINK] infection / IF-4.4 (text) 「肺囊蟲肺炎」: 使用高劑量類固醇時，尤其合併免疫抑制劑，醫師可能會評估是否用藥預防肺囊蟲肺炎。  〔EULAR 2022・建議強度 B/D〕

## zoster — 帶狀疱疹（皮蛇）
aliases on site: 帶狀疱疹, 皮蛇   (category: condition; link scope: card)
- [LINK] common / CM-5.2 (text) 「帶狀疱疹」: 風濕病患者使用免疫抑制藥物期間，活性減毒疫苗建議延後接種，包括活性的帶狀疱疹（皮蛇）疫苗；流感疫苗請選非活性的。接種前請先問風濕科醫師。  〔ACR 2022・建議〕
- [repeat] common / CM-5.2 (text) 「皮蛇」: 風濕病患者使用免疫抑制藥物期間，活性減毒疫苗建議延後接種，包括活性的帶狀疱疹（皮蛇）疫苗；流感疫苗請選非活性的。接種前請先問風濕科醫師。  〔ACR 2022・建議〕
- [LINK] infection / infection-zoster (title) 「皮蛇」: 皮蛇與水痘
- [repeat] infection / infection-zoster (summary) 「皮蛇」: 免疫力低時較易得皮蛇；沒水痘免疫力者接觸病人後盡快告訴醫師。
