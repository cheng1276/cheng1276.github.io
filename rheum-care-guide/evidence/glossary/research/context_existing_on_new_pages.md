## muscle-strengthening — 肌力訓練（阻力訓練）  (aliases: 肌力訓練 / 阻力訓練; scope: card)
- [LINK] osteoporosis / OP-3.1 (text) 「肌力訓練」: 規律做負重運動（例如走路、爬樓梯、跳舞、太極拳）和肌力訓練，並依自己的需要和能力調整。  〔NOGG 2024・強烈建議〕
- [repeat] osteoporosis / OP-3.3 (text) 「肌力訓練」: 肌力訓練要循序漸進增加強度，並練到腹部和背部肌肉；練腹部時，仰臥起坐這類反覆彎腰的動作要小心。  〔加拿大骨鬆指引 2023・建議；NOGG 2024・指引說明〕
- [repeat] osteoporosis / OP-3.4 (text) 「肌力訓練」: 散步、瑜伽等活動，能安全進行（必要時調整動作）就可以做；但要加在平衡、功能性和肌力訓練之外，而不是取代它們。  〔加拿大骨鬆指引 2023・建議〕

## weight-bearing — 負重運動  (aliases: 負重運動; scope: card)
- [LINK] oa / OA-M2 (fact) 「負重運動」: 美國 ACR 指引強烈建議膝、髖關節退化的人規律運動。研究回顧也發現，膝關節負重運動看來不會傷害軟骨，但證據品質低。  〔ACR 2019・強烈建議；系統性回顧 2019・研究顯示〕
- [LINK] osteoporosis / OP-3.1 (text) 「負重運動」: 規律做負重運動（例如走路、爬樓梯、跳舞、太極拳）和肌力訓練，並依自己的需要和能力調整。  〔NOGG 2024・強烈建議〕

## multicomponent — 多元活動（有氧、肌力與平衡）  (aliases: 多元活動 / 綜合性的運動課程; scope: card)
- [LINK] osteoporosis / OP-5.1 (text) 「綜合性的運動課程」: 骨質疏鬆或曾因輕微外力骨折的人，請醫療人員評估跌倒風險；有風險的人，建議參加改善平衡或綜合性的運動課程。  〔NOGG 2024・強烈建議〕

## range-of-motion — 關節活動度運動  (aliases: 關節活動度運動 / 頸胸腰椎活動度; scope: card)
- [LINK] oa / OA-3.4 (text) 「關節活動度運動」: 關節疼痛發作時，可能做不了高強度活動，但散步或關節活動度運動，或許還做得到。  〔EULAR 2025・指引說明〕

## physical-therapy — 物理治療  (aliases: 物理治療師 / 物理治療; scope: page)
- [LINK] oa / OA-2.4 (text) 「物理治療」: 可以考慮在專業人員指導下運動；多數人在病程中某些時候，轉介物理治療或職能治療可能有幫助。  〔NICE 2022・建議；ACR 2019・指引說明〕
- [LINK] osteoporosis / OP-4.2 (text) 「物理治療師」: 彎腰或搬東西時，從髖部和膝蓋彎曲、保持上背挺直，東西靠近身體；可請物理治療師或職能治療師教您安全的做法。  〔英國骨鬆運動共識 2022・專家共識；BHOF 2022・指引說明〕

## orthoses — 副木、護具與矯具  (aliases: 副木; scope: card)
- [LINK] oa / oa-hand (summary) 「副木」: 做手部運動、善用輔具，大拇指根部退化可考慮副木。

## uric-acid — 尿酸與高尿酸血症  (aliases: 高尿酸血症 / 血中尿酸 / 尿酸; scope: card)
- [LINK] labs / labs-intro (intro) 「尿酸」: 健檢報告出現抗核抗體、類風濕因子、抗CCP抗體陽性或尿酸偏高時，這頁說明它們的意思；是否生病，要由醫師合併症狀與檢查判斷。
- [LINK] labs / labs-urate (title) 「尿酸」: 尿酸高但沒有痛風
- [repeat] labs / labs-urate (summary) 「尿酸」: 尿酸高是痛風的危險因子，但不等於痛風。
- [repeat] labs / LB-5.1 (text) 「血中尿酸」: 血中尿酸偏高，但從沒有痛風發作，也沒有痛風石，稱為無症狀高尿酸血症。  〔ACR 2020・指引說明〕
- [repeat] labs / LB-5.1 (text) 「高尿酸血症」: 血中尿酸偏高，但從沒有痛風發作，也沒有痛風石，稱為無症狀高尿酸血症。  〔ACR 2020・指引說明〕
- [repeat] labs / LB-5.2 (text) 「尿酸」: 尿酸高是發生痛風的重要危險因子，但不能只憑尿酸高就診斷痛風。  〔EULAR 2018・指引說明；G-CAN 2019・專家共識〕
- [repeat] labs / LB-5.2 (text) 「尿酸」: 尿酸高是發生痛風的重要危險因子，但不能只憑尿酸高就診斷痛風。  〔EULAR 2018・指引說明；G-CAN 2019・專家共識〕
- [repeat] labs / LB-5.3 (text) 「尿酸」: 國外研究顯示，尿酸超過9 mg/dL的人，5年內約2成發生痛風；超過10 mg/dL的人，15年內約一半。  〔ACR 2020・指引說明；EULAR 2018・指引說明〕
- [LINK] labs / labs-urate-treatment (title) 「尿酸」: 尿酸高要吃藥嗎？
- [repeat] labs / LB-6.1 (text) 「尿酸」: 沒有痛風的高尿酸要不要吃降尿酸藥，各國指引看法不同，並不是每個人都需要。  〔ACR 2020・不建議；中國指引 2024・指引說明〕
- [repeat] labs / LB-6.2 (text) 「尿酸」: 調整生活型態（例如飲食和運動）是處理高尿酸和痛風的基礎。  〔香港風濕病學會 2023・指引說明〕
- [repeat] labs / LB-6.3 (text) 「尿酸」: 多數情況下，高尿酸可以在基層醫療（如家庭醫師）處理；一般治療效果不好時，可能需要轉介專科。  〔香港風濕病學會 2023・指引說明〕
- [LINK] labs / LB-M3 (belief) 「尿酸」: 尿酸高就是痛風。  〔EULAR 2018・指引說明；ACR 2020・指引說明〕
- [repeat] labs / LB-M3 (fact) 「尿酸」: 不是。尿酸高是痛風的重要危險因子，但不能只憑它診斷痛風；國外研究中，尿酸超過9 mg/dL的人，5年內約2成發生痛風。  〔EULAR 2018・指引說明；ACR 2020・指引說明〕
- [repeat] labs / LB-M3 (fact) 「尿酸」: 不是。尿酸高是痛風的重要危險因子，但不能只憑它診斷痛風；國外研究中，尿酸超過9 mg/dL的人，5年內約2成發生痛風。  〔EULAR 2018・指引說明；ACR 2020・指引說明〕
- [repeat] labs / LB-M4 (belief) 「尿酸」: 尿酸高，就一定要吃降尿酸藥。  〔ACR 2020・不建議；中國指引 2024・指引說明〕
- [repeat] labs / LB-M4 (fact) 「尿酸」: 不一定。沒有痛風的高尿酸要不要用藥，各國指引看法不同，並不是每個人都需要；已在用藥的人請先和醫師討論，不要自行停藥。  〔ACR 2020・不建議；中國指引 2024・指引說明〕

## iu — 國際單位（IU）  (aliases: 國際單位; scope: card)
- [LINK] osteoporosis / OP-2.4 (text) 「國際單位」: 維生素D不足或有不足風險的人（例如長期待在家裡、住在照護機構），建議和醫師討論後，每天至少補充800國際單位。  〔NOGG 2024・強烈建議〕

## oral-glucocorticoid — 口服類固醇  (aliases: 口服類固醇 / 類固醇; scope: card)
- [LINK] osteoporosis / osteoporosis-intro (intro) 「類固醇」: 這頁整理停經後女性與50歲以上男性的骨骼保健：認識警訊、飲食、運動、防跌倒與治療。長期用類固醇，或想看活動量與菸酒建議，請見共通照護頁。
- [LINK] infection / infection-intro (intro) 「類固醇」: 使用類固醇、免疫抑制劑、生物製劑等藥物治療風濕病時，某些感染可能更容易發生或更嚴重。這頁整理治療前篩檢、治療中追蹤和生病時的應對。
- [LINK] infection / IF-2.1 (text) 「類固醇」: 台灣結核病比歐美常見得多；疾管署指出，免疫風濕病人因疾病本身和類固醇、免疫抑制劑治療，結核病風險比一般人高出許多。  〔TRA 2020・指引說明；疾管署・指引說明〕
- [repeat] infection / IF-2.2 (text) 「類固醇」: 用生物製劑或口服標靶藥物前，要先篩檢潛伏結核；風險較高的人，用其他抗風濕藥物或類固醇前也可能需要。  〔EULAR 2022・建議強度 B/D；BSR 2019・強烈建議（1B）〕
- [LINK] infection / IF-3.1 (text) 「類固醇」: 開始免疫抑制治療前，都應檢查 B 型肝炎表面抗原、表面抗體和核心抗體；類固醇則依劑量和使用時間決定。  〔EULAR 2022・建議強度 C；APASL 2021・建議〕
- [repeat] infection / IF-3.2 (text) 「類固醇」: 免疫抑制治療可能讓 B 型肝炎再活化（再度活躍），已痊癒者也可能。類固醇看劑量：帶原者持續用較高劑量風險中到高，低劑量或已痊癒者風險較低。  〔BSR 2025・指引說明；APASL 2021・指引說明〕
- [LINK] infection / infection-steroid (title) 「類固醇」: 使用類固醇時
- [repeat] infection / IF-4.1 (text) 「類固醇」: ACR 類風濕性關節炎指引指出：觀察性研究發現，類固醇劑量越高、用得越久，和嚴重感染風險越高有關；醫師會盡量用最低有效劑量、最短時間。  〔ACR 2021・指引說明〕
- [repeat] infection / IF-4.2 (text) 「類固醇」: 不要漏吃或自行突然停用類固醇；口服劑量高於身體自然分泌量時，藥量突然不足可能引起需緊急處理的腎上腺危象。  〔ESE/ES 2024・指引說明〕
- [repeat] infection / IF-4.3 (text) 「類固醇」: 長期用或剛停用類固醇的人，發燒或感染需用抗生素時，可能需要暫時補充類固醇，以免腎上腺功能不足（不是治療感染）；請事先問醫師，感染也要就醫。  〔ESE/ES 2024・良好實務建議〕
- [repeat] infection / IF-4.3 (text) 「類固醇」: 長期用或剛停用類固醇的人，發燒或感染需用抗生素時，可能需要暫時補充類固醇，以免腎上腺功能不足（不是治療感染）；請事先問醫師，感染也要就醫。  〔ESE/ES 2024・良好實務建議〕
- [repeat] infection / IF-4.4 (text) 「類固醇」: 使用高劑量類固醇時，尤其合併免疫抑制劑，醫師可能會評估是否用藥預防肺囊蟲肺炎。  〔EULAR 2022・建議強度 B/D〕
- [LINK] infection / IF-6.3 (text) 「類固醇」: 用生物製劑、口服標靶藥物、免疫抑制劑或高劑量類固醇時，可請醫療團隊提供飲食與環境衛生建議，減少李斯特菌、沙門氏菌等感染。  〔EULAR 2022・專家共識〕
- [repeat] infection / IF-6.T (text) 「類固醇」: 生病時請盡快就醫；藥物要不要暫停或調整，由醫師決定；類固醇不可自行突然停用。  〔編輯加註・安全提醒〕
- [LINK] infection / IF-M3 (belief) 「類固醇」: 只有生物製劑會增加感染風險，類固醇和傳統抗風濕藥物不用擔心。  〔EULAR 2022・指引說明；疾管署・指引說明〕

- [LINK] infection / IF-3.1 (text) 「免疫抑制治療」: 開始免疫抑制治療前，都應檢查 B 型肝炎表面抗原、表面抗體和核心抗體；類固醇則依劑量和使用時間決定。  〔EULAR 2022・建議強度 C；APASL 2021・建議〕
- [repeat] infection / IF-3.2 (text) 「免疫抑制治療」: 免疫抑制治療可能讓 B 型肝炎再活化（再度活躍），已痊癒者也可能。類固醇看劑量：帶原者持續用較高劑量風險中到高，低劑量或已痊癒者風險較低。  〔BSR 2025・指引說明；APASL 2021・指引說明〕
- [repeat] infection / IF-3.5 (text) 「免疫抑制治療」: 抗病毒藥在免疫抑制治療結束後，還要繼續吃一段時間；請不要自行停用，何時停藥由醫師評估，停藥後也要繼續抽血追蹤。  〔AASLD 2018・專家共識；APASL 2021・指引說明〕
- [LINK] infection / IF-4.4 (text) 「免疫抑制劑」: 使用高劑量類固醇時，尤其合併免疫抑制劑，醫師可能會評估是否用藥預防肺囊蟲肺炎。  〔EULAR 2022・建議強度 B/D〕
- [LINK] infection / IF-6.3 (text) 「免疫抑制劑」: 用生物製劑、口服標靶藥物、免疫抑制劑或高劑量類固醇時，可請醫療團隊提供飲食與環境衛生建議，減少李斯特菌、沙門氏菌等感染。  〔EULAR 2022・專家共識〕
- [LINK] infection / IF-M3 (fact) 「免疫抑制劑」: 不只生物製劑。有些證據顯示，使用類固醇或傳統抗風濕藥物，潛伏結核再活化的風險也會增加；疾管署也指出，免疫風濕病人因疾病本身和類固醇、免疫抑制劑治療，結核病風險比一般人高出許多。  〔EULAR 2022・指引說明；疾管署・指引說明〕
- [repeat] infection / IF-M4 (fact) 「免疫抑制治療」: 不應該跟著停。免疫抑制治療停止後，B 型肝炎仍可能再活化，抗病毒藥還要繼續一段時間；請不要自行停用，何時停藥由醫師評估，停藥後也要繼續抽血追蹤。  〔AASLD 2018・專家共識；APASL 2021・指引說明〕
- [LINK] infection / IF-S1 (text) 「免疫抑制藥物」: 使用生物製劑期間出現帶狀疱疹（皮蛇），請盡快就醫，治療方式和一般人相同；使用 JAK 抑制劑等其他免疫抑制藥物時出現皮蛇，也請盡快就醫。  〔BSR 2019・建議（2C）〕

## biologic — 生物製劑  (aliases: 生物製劑; scope: card)
- [LINK] infection / infection-intro (intro) 「生物製劑」: 使用類固醇、免疫抑制劑、生物製劑等藥物治療風濕病時，某些感染可能更容易發生或更嚴重。這頁整理治療前篩檢、治療中追蹤和生病時的應對。
- [LINK] infection / infection-tb (summary) 「生物製劑」: 用生物製劑前先驗潛伏結核；陽性時把治療完整做完。
- [repeat] infection / IF-2.2 (text) 「生物製劑」: 用生物製劑或口服標靶藥物前，要先篩檢潛伏結核；風險較高的人，用其他抗風濕藥物或類固醇前也可能需要。  〔EULAR 2022・建議強度 B/D；BSR 2019・強烈建議（1B）〕
- [repeat] infection / IF-2.4 (text) 「生物製劑」: 潛伏結核檢驗陽性時，通常要先開始潛伏結核治療，再用生物製劑；治療完整做完，才能提供約 9 成的保護。  〔BSR 2019・建議（2C）；疾管署・指引說明〕
- [LINK] infection / IF-5.2 (text) 「生物製劑」: 使用 JAK 抑制劑（一種口服標靶藥物）時，帶狀疱疹比使用生物製劑時更常見。  〔國際共識 2024・建議強度 B〕
- [LINK] infection / IF-6.2 (text) 「生物製劑」: 感染時，治療有時需要暫停；例如嚴重感染時，醫師通常會先暫停生物製劑，等感染好了再恢復。  〔BSR 2019・強烈建議（1A）〕

- [LINK] infection / IF-M1 (belief) 「生物製劑」: 有 B 型肝炎，就不能使用生物製劑。  〔BSR 2019・強烈建議（1C）〕
- [repeat] infection / IF-M1 (fact) 「生物製劑」: 不一定。經醫師評估風險和好處，配合適當的抗病毒藥物，並和肝膽腸胃科醫師密切合作，使用生物製劑可能是安全的。  〔BSR 2019・強烈建議（1C）〕
- [repeat] infection / IF-M3 (belief) 「生物製劑」: 只有生物製劑會增加感染風險，類固醇和傳統抗風濕藥物不用擔心。  〔EULAR 2022・指引說明；疾管署・指引說明〕
- [repeat] infection / IF-M3 (fact) 「生物製劑」: 不只生物製劑。有些證據顯示，使用類固醇或傳統抗風濕藥物，潛伏結核再活化的風險也會增加；疾管署也指出，免疫風濕病人因疾病本身和類固醇、免疫抑制劑治療，結核病風險比一般人高出許多。  〔EULAR 2022・指引說明；疾管署・指引說明〕

## osteoporosis — 骨質疏鬆  (aliases: 骨質疏鬆; scope: card)
- [LINK] oa / OA-4.5 (text) 「骨質疏鬆」: 膝關節退化、且體重過重或肥胖而需要減重的人，宜逐步、持續地減重；快速減重曾被發現與關節不穩、肌少症和骨質疏鬆等風險有關。  〔新加坡 ACE 2026・指引說明〕

- [LINK] osteoporosis / OP-5.1 (text) 「骨質疏鬆」: 骨質疏鬆或曾因輕微外力骨折的人，請醫療人員評估跌倒風險；有風險的人，建議參加改善平衡或綜合性的運動課程。  〔NOGG 2024・強烈建議〕
- [LINK] osteoporosis / OP-6.1 (text) 「骨質疏鬆」: 骨質疏鬆是長期疾病，目前無法根治，常需要長期治療；骨密度進步，也不代表已經痊癒。  〔NOGG 2024、BHOF 2022・指引說明〕
- [LINK] osteoporosis / OP-M2 (belief) 「骨質疏鬆」: 只有女性才會骨質疏鬆。  〔NOGG 2024、加拿大骨鬆指引 2023・指引說明〕
- [repeat] osteoporosis / OP-M3 (belief) 「骨質疏鬆」: 多吃鈣片，就能預防或治療骨質疏鬆。  〔ESCEO/IOF 2019、澳洲骨鬆指引 2024・指引說明〕
- [repeat] osteoporosis / OP-M4 (belief) 「骨質疏鬆」: 骨質疏鬆就不能運動，以免骨折。  〔NOGG 2024、BHOF 2022・指引說明〕
