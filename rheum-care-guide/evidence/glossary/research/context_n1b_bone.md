## bmd — 骨密度檢查
aliases on site: 骨密度檢查, 骨密度   (category: test; link scope: card)
- [LINK] osteoporosis / OP-1.3 (text) 「骨密度檢查」: 65歲以上女性、70歲以上男性，可和醫師討論是否做骨密度檢查。  〔BHOF 2022、台灣骨鬆學會 2021・指引說明〕
- [repeat] osteoporosis / OP-1.4 (text) 「骨密度檢查」: 停經後女性和50歲以上男性，如果有骨折風險因子或成年後曾骨折，也可和醫師討論是否做骨密度檢查。  〔BHOF 2022、台灣骨鬆學會 2021・指引說明〕
- [LINK] osteoporosis / OP-6.1 (text) 「骨密度」: 骨質疏鬆是長期疾病，目前無法根治，常需要長期治療；骨密度進步，也不代表已經痊癒。  〔NOGG 2024、BHOF 2022・指引說明〕

## fragility-fracture — 輕微外力骨折（脆弱性骨折）
aliases on site: 輕微外力就骨折, 輕微外力骨折   (category: condition; link scope: card)
- [LINK] osteoporosis / osteoporosis-fracture (summary) 「輕微外力就骨折」: 超過50歲輕微外力就骨折，要想到骨質疏鬆。
- [repeat] osteoporosis / OP-1.1 (text) 「輕微外力就骨折」: 超過50歲的人，輕微外力就骨折（例如從站立的高度跌倒），應考慮可能是骨質疏鬆。  〔澳洲骨鬆指引 2024・建議強度 A〕
- [LINK] osteoporosis / OP-5.1 (text) 「輕微外力骨折」: 骨質疏鬆或曾因輕微外力骨折的人，請醫療人員評估跌倒風險；有風險的人，建議參加改善平衡或綜合性的運動課程。  〔NOGG 2024・強烈建議〕
- [LINK] osteoporosis / OP-M2 (fact) 「輕微外力骨折」: 男性也會。英國指引估計，在英國約每5位男性就有1位一生中會因輕微外力骨折；男性常沒被檢查和治療，骨折後的結果往往也比女性差。  〔NOGG 2024、加拿大骨鬆指引 2023・指引說明〕

## vertebral-fracture — 脊椎骨折
aliases on site: 脊椎骨折   (category: condition; link scope: card)
- [LINK] axspa / AS-3.T (text) 「脊椎骨折」: 台灣常以機車、腳踏車代步，宜及早和醫師討論骨質疏鬆與脊椎骨折的風險。  〔TRA 2020・指引說明〕
- [LINK] osteoporosis / OP-6.3 (text) 「脊椎骨折」: 使用每半年打一次的骨鬆皮下注射針劑（denosumab）時，不要自行停藥或延後打針；需要停藥時，請醫師安排接續治療，以免脊椎骨折風險增加。  〔NOGG 2024・強烈建議〕
- [LINK] osteoporosis / OP-M1 (fact) 「脊椎骨折」: 骨質流失本身沒有症狀，常到骨折才發現。約三分之二的脊椎骨折沒有明顯症狀，但不論有沒有症狀，都代表之後更容易再骨折。  〔澳洲骨鬆指引 2024、BHOF 2022・指引說明〕
- [LINK] osteoporosis / OP-S1 (text) 「脊椎骨折」: 停經後女性和50歲以上男性，身高變矮4公分以上、背變駝，或有骨鬆風險又突然背痛（尤其是中上背），請告訴醫師，可能是脊椎骨折。  〔NOGG 2024・強烈建議〕

## bisphosphonate — 雙磷酸鹽類藥物
aliases on site: 雙磷酸鹽類骨鬆藥, 雙磷酸鹽   (category: drug; link scope: card)
- [LINK] osteoporosis / OP-6.4 (text) 「雙磷酸鹽類骨鬆藥」: 使用雙磷酸鹽類骨鬆藥，或每半年打一次的骨鬆皮下注射針劑期間，保持口腔清潔、定期看牙醫；牙齒鬆動、口腔疼痛或腫脹時，請告訴醫師或牙醫師。  〔NOGG 2024・強烈建議；加拿大骨鬆指引 2023・良好實務建議〕
- [LINK] osteoporosis / OP-S2 (text) 「雙磷酸鹽類骨鬆藥」: 使用雙磷酸鹽類骨鬆藥，或每半年打一次的骨鬆皮下注射針劑（denosumab）期間，出現原因不明的大腿、鼠蹊部或髖部疼痛，請告訴醫師。  〔NOGG 2024・強烈建議〕
