## sarcopenia — 肌少症
aliases on site: 肌少症   (category: condition; link scope: card)
- [LINK] oa / OA-4.5 (text) 「肌少症」: 膝關節退化、且體重過重或肥胖而需要減重的人，宜逐步、持續地減重；快速減重曾被發現與關節不穩、肌少症和骨質疏鬆等風險有關。  〔新加坡 ACE 2026・指引說明〕

## doms — 延遲性肌肉痠痛
aliases on site: 延遲性肌肉痠痛   (category: exercise; link scope: card)
- [LINK] oa / OA-3.2 (text) 「延遲性肌肉痠痛」: 運動後48到72小時內疼痛增加，可能是延遲性肌肉痠痛，屬正常反應，剛開始運動的人尤其如此。  〔EULAR 2025・指引說明〕

## paraffin — 石蠟浴
aliases on site: 石蠟浴   (category: rehab; link scope: card)
- [LINK] oa / OA-5.4 (text) 「石蠟浴」: 手部關節可以考慮使用石蠟浴，這是一種手部熱療方式；使用時注意溫度，避免燙傷。  〔ACR 2019・建議〕

- [LINK] oa / oa-aids (summary) 「楔形鞋墊」: 善用助行器和舒適的鞋子；楔形鞋墊和TENS不建議。

## glucosamine — 葡萄糖胺
aliases on site: 葡萄糖胺   (category: drug; link scope: card)
- [LINK] oa / OA-M1 (belief) 「葡萄糖胺」: 吃葡萄糖胺可以治療退化性關節炎。  〔ACR 2019・強烈不建議；NICE 2022・不建議〕
- [repeat] oa / OA-M1 (fact) 「葡萄糖胺」: 美國 ACR 指引強烈不建議用葡萄糖胺治療膝、髖或手部退化性關節炎，英國 NICE 也不建議。最可靠的研究顯示，它比起安慰劑沒有明顯好處。  〔ACR 2019・強烈不建議；NICE 2022・不建議〕

## balance-functional — 平衡與功能性訓練
aliases on site: 平衡和功能性訓練, 功能性訓練   (category: exercise; link scope: card)
- [LINK] osteoporosis / OP-3.2 (text) 「平衡和功能性訓練」: 做平衡和功能性訓練（例如從椅子上站起來再坐下、爬樓梯），降低跌倒風險。  〔加拿大骨鬆指引 2023・強烈建議〕
- [LINK] osteoporosis / OP-5.2 (text) 「平衡和功能性訓練」: 長者預防跌倒的運動，要有平衡和功能性訓練（例如從椅子站起、跨步），每週3次以上，逐步加強至少12週；做得更久，效果更好。  〔世界跌倒指引 2022・強烈建議（1A）〕
