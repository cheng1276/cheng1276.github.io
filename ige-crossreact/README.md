# IgE 交叉反應判讀器

網址：https://cheng1276.github.io/ige-crossreact/ （需要密碼才能開啟）

給醫師判讀多重過敏原檢測（例如 BioIC 40 項）的輔助工具。多重檢測常出現許多項同時陽性、病人卻沒有相關症狀，其中一部分是臨床意義不大的交叉反應。輸入各項 Class 後，工具會依陽性組合評估 CCD、profilin、tropomyosin 等 17 種共同結構或非特異反應模式，把每一項分成「需優先處理」「請依病史確認」「多為交叉或非特異反應」「已可耐受」四類，並列出可加做的分子過敏原檢查。

## 功能

- 面板：BioIC AD40、AQ40、AS40（含分子項目）與自訂面板；點選圓孔設定 Class，或貼上報告文字自動帶入代碼、中英文名稱、數值或 Class 與總 IgE。
- 病人背景（選填）：年齡層、臨床表現、背景（素食、蜱蟲叮咬、乳膠職業暴露等），以及已做過的分子或標記檢查（例如 CCD 標記、Phl p 12、Der p 10、α-Gal）；已知結果可確認或排除某一型。
- 判讀結果：各交叉模式的可能性分數與支持、反對的理由；逐項臨床意義與建議的分子檢查；同源物種提示（例如屋塵蟎與粉塵蟎）。把某一項標記為「吃了有症狀」時，同家族的其他陽性項目會附上文獻報告的臨床交叉機率（例如牛奶過敏者對羊奶 >90%）。
- 泛過敏原圖譜：判讀原則、BioIC 陽性組合速查表、臨床交叉機率表、19 型泛過敏原的分子、分布、數據、臨床意義與確認方式。
- 8 個虛構範例；可一鍵複製判讀摘要。
- 輸入的資料只在瀏覽器中計算，不會上傳或保存。

## 判讀方式

- 每種交叉模式以規則評 0–100 分：看陽性項目的分布（例如 CCD 為多種不同科的植物同時陽性，而蛋、奶、魚、肉、皮屑陰性）、Class 高低、同家族中誰最高（通常是原發致敏來源），再依症狀、背景與已知標記檢查加減分。
- CCD 依 Lee 2025（[DOI](https://doi.org/10.3390/diagnostics15222869)）的資料加權：多重檢測加入 CCD 阻斷劑後，Class 1 約 91%、Class 2 約 80%、Class 3 約 42% 轉陰，Class 4 以上不到一成。
- 每種模式的臨床意義分三級：通常不具臨床意義（CCD、profilin、polcalcin、草花粉–穀類、真菌、總 IgE 偏高的非特異低陽性；profilin 遇到有口腔過敏的食物時改為視病史而定）、視病史而定（PR-10、豆類與堅果儲藏蛋白、tropomyosin、血清白蛋白、Gal d 5）、常具臨床意義（nsLTP、parvalbumin、α-Gal、乳膠–水果、牛奶–羊奶）。
- Class 切點：BioIC（AU）小於 1 為 Class 0，1–2、2–4、4–8、8–16、16–32、大於 32 依序為 Class 1–6；kU/L 依 ImmunoCAP 慣用切點 0.35、0.7、3.5、17.5、50、100。
- 分數代表「此陽性組合可被某一結構解釋的程度」，不是確診機率。

## 密碼保護

- 網頁內容以 AES-256-GCM 加密後放在 `index.html`，金鑰由密碼經 PBKDF2-HMAC-SHA256（600,000 次）導出。開啟時在瀏覽器裡解密，密碼不會傳到任何伺服器，也沒有寫在任何檔案裡。
- 原始檔同樣加密成 `source.enc`；公開儲存庫裡沒有明文的網頁內容或原始檔。
- 可勾選「在這台裝置記住密碼」；頁尾的「鎖定此頁」會清除記住的密碼。
- 這是靜態網站的前端加密，能擋住一般訪客；密碼越長、越不規則越安全。不要用來保存病人資料。
- 更換密碼後，記住舊密碼的裝置會自動回到密碼畫面。

## 內容狀態

- 試用版。文獻檢索、判讀規則與程式由 AI（Claude）協助完成；132 篇參考文獻的作者、標題、期刊、年份、PMID 與 DOI 均已和 PubMed 核對。評分規則尚未以真實病例驗證，也尚未經醫師逐項審閱。
- 最後更新：2026 年 10 月 16 日（同日加上密碼保護）。

## 修改內容

以下指令在 `ige-crossreact/` 資料夾執行。密碼可用環境變數 `IGE_PASSWORD` 提供，沒有設定時會在終端機詢問。

1. 還原原始檔：`node tools/protect.js unpack`
2. 編輯 `src/` 裡的檔案：過敏原與面板在 `data.js`，評分規則在 `engine.js`，說明文字與範例在 `kb.js`，文獻在 `refs.js`。
3. 執行 `node src/test_engine.js`，確認各範例的判讀結果合理。
4. 產生明文網頁：`python3 src/build.py`
5. 加密：`node tools/protect.js page`（產生 `index.html`）與 `node tools/protect.js pack`（產生 `source.enc`）
6. 提交 `index.html` 與 `source.enc` 並推送；GitHub Pages 會在幾分鐘內更新。

更換密碼：第 5 步的兩個指令都加上 `--new-password`，再通知使用者新密碼。沒有加這個選項時，工具會先確認密碼能解開現有的 `source.enc`，避免打錯字把網頁鎖住。

## 使用前請先了解

本工具供醫師判讀多重過敏原檢測時參考，不能取代臨床判斷，也不是診斷工具。萃取物檢測無法單獨證明交叉反應；是否需要避免某種食物或接觸，請結合病史、皮膚點刺測試、分子過敏原檢測或口服挑戰判斷。多重萃取面板對 α-Gal、PR-10 等的敏感度差，陰性結果不能排除過敏。BioIC 面板組成取自洹藝科技（Agnitio）公開的過敏原項目表，本工具與該公司無關。
